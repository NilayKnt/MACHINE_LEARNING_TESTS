## 📌 About the Project

This repository serves as an end-to-end collection of **Data Science and Machine Learning** projects, ranging from fundamental raw data preprocessing to advanced Gradient Boosting algorithms and Deep Learning architectures. Each directory addresses a specific problem, evaluates model performances, or implements hands-on techniques.

---

## 🛠️ Tech Stack & Libraries

* **Data Analysis & Preprocessing:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Classical Machine Learning:** Scikit-Learn, XGBoost, LightGBM, CatBoost
* **Deep Learning Frameworks:** PyTorch, Keras / TensorFlow

---

## 📁 Repository Structure & Modules

| Module / Folder | Core Topics & Methods | Tech Stack |
| :--- | :--- | :--- |
| **`01-Data-Preprocessing`** | Missing Value Imputation, Outlier Detection, Feature Scaling & Encoding | `pandas`, `numpy`, `scikit-learn` |
| **`02-Data-Visualization`** | Exploratory Data Analysis (EDA), Correlation Heatmaps, Distribution Plots | `matplotlib`, `seaborn` |
| **`03-Regression-Models`** | Linear / Ridge / Lasso Regression, Performance Metrics (RMSE, R²) | `scikit-learn` |
| **`04-Tree-And-Boosting`** | Decision Trees, Random Forest, **XGBoost**, **Gradient Boosting** | `xgboost`, `scikit-learn` |
| **`05-Deep-Learning-Keras`** | ANN, CNN, Model Training, Loss & Accuracy Curve Analysis | `keras`, `tensorflow` |
| **`06-Deep-Learning-PyTorch`** | Custom Datasets, Tensors, Neural Network Training Loops | `torch`, `torchvision` |
